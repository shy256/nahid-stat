# 历史记忆归档

本目录保存仍有历史检索价值、但无需常驻热索引的条目。当前无历史条目。

- 文件名为 `YYYY-MM.md`，按归档月份组织；条目保留原 ID、原记录日期、作用域、状态和可复核证据，并注明归档日期。
- 热索引与归档不重复保存同一条完整事实；热索引可保留简短检索入口。更新已有 ID 前，必要时先按 ID 搜索归档。
- 模块细节优先进入专题文档；已完成进度、失效结论、敏感信息不能作为归档内容保留。
- 用户要求忘记某条信息时，检查并移除热索引、专题文档和归档中的对应内容，不能以“保留历史”为由继续存储。
- 仅在热索引未命中且任务确实需要历史背景时检索；不要默认通读全部归档。

在仓库根目录按实际关键词检索，例如：

```powershell
rg -n -i -- '关键词|错误码|模块名|条目ID' .agents/memory/archive/
```
